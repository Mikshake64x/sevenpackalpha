# macOS Installation

Thank you for downloading

## Installation

1. Open the downloaded archive.
2. Copy the plugin to the appropriate folder:

**VST3**

```
/Library/Audio/Plug-Ins/VST3/
```

**Audio Unit (AU)**

```
/Library/Audio/Plug-Ins/Components/
```

3. If prompted, enter your administrator password.
4. Launch your DAW and rescan your plugins if necessary.

## Apple Security

If macOS prevents the plugin from loading because it is from an unidentified developer:

1. Open **System Settings → Privacy & Security**.
2. Scroll to the **Security** section.
3. Click **Open Anyway** if the option appears.
4. Restart your DAW.

## Requirements

* macOS 11 (Big Sur) or later
* Apple Silicon or Intel Mac
* AU or VST3 compatible host

If you experience any issues, feel free to contact us.

Enjoy!
