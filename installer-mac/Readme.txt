Sevenpack Alpha for macOS

This installer copies:

  - VST3 plugin:            /Library/Audio/Plug-Ins/VST3/SevenpackAlpha.vst3
  - Standalone application: /Applications/SevenpackAlpha.app

Both are selected by default. To install only one of them, click
"Customize" on the Installation Type step.

After installing, launch your DAW and rescan your plugins if necessary.


Apple Security

If macOS refuses to open this installer because it is from an
unidentified developer:

  1. Open System Settings > Privacy & Security.
  2. Scroll to the Security section.
  3. Click "Open Anyway", then open the installer again.


Requirements

  - macOS 11 (Big Sur) or later
  - Apple Silicon or Intel Mac
  - VST3 compatible host, or the standalone application

If you experience any issues, feel free to contact us.
